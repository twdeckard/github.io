# Family Data Utility

This repository contains the static web content used for a private,
non-commercial application.

The application is used by a small number of authorized users to access
their own Google Drive content with read-only permissions for personal
data-management purposes.

No credentials, access tokens, account identifiers, storage locations,
or private user data are stored in this repository.

## Privacy

See the published privacy policy for information about how Google user
data is accessed and handled.

## Security

This repository contains only static public-facing documentation.
Operational configuration and authentication credentials are maintained
separately.
