Family Data Utility Privacy Policy

Family Data Utility is a private, non-commercial application used by a small number of authorized users for personal data-management purposes.

Google user data accessed

The application requests read-only access to Google Drive file metadata and file contents.

Use of data

Google user data is used only by authorized users for private, non-commercial personal data-management purposes. The application does not modify or delete files in Google Drive.

Sharing of data

Google user data is not sold, transferred, or shared with third parties.

Storage and processing

Data accessed through the application is handled only for the purposes authorized by the user. Authentication credentials and private user data are not published through this website.

Revoking access

Users may revoke the application's access to their Google account at any time through their Google Account security settings.
